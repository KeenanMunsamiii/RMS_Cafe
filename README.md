# RMS Cafe Management System

RMS_Cafe is a comprehensive, native Windows desktop application built with C# and WPF. Designed specifically to handle the unique workflows of a cafe operating within an active automotive repair center, it combines a streamlined Point of Sale (POS) terminal with robust back-office management tools.

The system provides a seamless experience for cashiers and administrators alike, featuring a clean, modern UI optimized for standard desktop displays.

Key Features:

Modern POS Terminal: Fast, categorized checkout system with support for custom items, discounts, and order notes.

Smart Inventory Management: Real-time stock tracking with automated low-stock threshold alerts.

Employee Management & Tabs: Dedicated tracking for staff accounts, role-based access, and integrated tracking for internal employee credit/tabs.

Comprehensive Analytics: Dynamic reporting dashboard for visualizing gross income, net sales, and inventory movement.

Premium UI/UX: A crisp, custom-styled interface featuring a bespoke black, white, and gold theme.

Built With:

-C# / .NET

-WPF (Windows Presentation Foundation) / XAML

-SQL
